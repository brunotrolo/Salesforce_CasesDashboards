# Shared Components

Componentes reutilizáveis entre micro frontends.

## Estrutura

```
src/
  ├── components/       # Componentes compartilhados
  ├── hooks/            # Custom hooks
  ├── types.ts          # Tipos TypeScript
  └── utils/            # Utilitários
```

## Componentes

- ReportCard
- ReportTable
- ReportFilters
