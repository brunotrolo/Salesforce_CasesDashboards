# Dashboard Frontend

Interface de visualização de relatórios.

## Estrutura

```
src/
  ├── components/       # Componentes React
  ├── pages/            # Páginas
  ├── api/              # Client HTTP
  ├── hooks/            # Custom hooks
  └── App.tsx           # Componente principal
```

## Funcionalidades

- Listagem de relatórios com filtros
- Visualização em tempo real
- Exportação (PDF, Excel, CSV)
- Favoritos e compartilhamento
- Agendamento de execução
- Busca full-text

## Setup

```bash
npm install
npm run dev
```
