# Builder Frontend

Interface para criação e edição de relatórios.

## Estrutura

```
src/
  ├── components/       # Componentes React
  ├── pages/            # Páginas (Create, Edit)
  ├── hooks/            # Custom hooks
  └── utils/            # Utilitários
```

## Funcionalidades

- Drag-and-drop de campos
- Seleção de data sources
- Preview em tempo real
- Validação de configurações
- Versionamento integrado
- Testes de resultados

## Setup

```bash
npm install
npm run dev
```
