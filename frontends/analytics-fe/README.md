# Analytics Frontend

Interface para análise e histórico de relatórios.

## Estrutura

```
src/
  ├── components/       # Componentes React
  ├── pages/            # Páginas
  ├── charts/           # Gráficos
  └── utils/            # Utilitários
```

## Funcionalidades

- Histórico de execuções
- Tendências e insights
- Análise de performance
- Comparação de períodos

## Setup

```bash
npm install
npm run dev
```
