Salesforce Cases Dashboard

Briefing executivo com análise gerencial de Cases do Salesforce em tempo real.

📊 Visão Diária 📈 Visão Semanal 💡 Oportunidades
ℹ️ Dados em tempo real via MCP
Dashboard consome dados reais do Salesforce via MCP SalesforceRead (SOQL queries somente leitura).

Visão Diária: Análise granular de hoje (volume, categorias, status, qualidade de dados)
Visão Semanal: Tendências e padrões (produtos, automação, SLA, oportunidades)
Oportunidades: 7 novos relatórios estratégicos identificados (SLA por categoria, Product Scorecard, RPA Expansion, etc)

Como usar

  1. Clique em "Ver Dashboard" acima
  2. O dashboard é autossuficiente (HTML + CSS + dados embutidos)
  3. Compartilhe o link ou exporte como PDF
  4. Integre em relatórios automáticos via GitHub Actions

Regenerar dashboard

python3 scripts/generate_dashboard.py

Configuração

Variáveis de ambiente necessárias:

  • SF_CLIENT_ID - Salesforce OAuth Client ID
  • SF_CLIENT_SECRET - Salesforce OAuth Client Secret
  • SF_REFRESH_TOKEN - Salesforce OAuth Refresh Token
